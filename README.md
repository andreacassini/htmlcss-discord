# Discord landing page

A static recreation of the Discord landing page, built to practise HTML and CSS layout.

**Live demo:** https://andreacassini.github.io/htmlcss-discord/

## What is in it

- Navigation bar
- "Your place to talk" hero section
- Footer, with Font Awesome icons

## Run

No build step. Open `index.html` in a browser.

## Status

A layout exercise with sample content. Part of my portfolio: [https://andreacassini.com/projects/discord](https://andreacassini.com/projects/discord)
